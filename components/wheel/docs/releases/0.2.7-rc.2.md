# art of sim rally 0.2.7-rc.2 — test release

This prerelease is for testing the updated controls binding flow and an optional
wheel rumble on gear changes. It includes the same steering, landing, crash and
SimHub telemetry behavior as 0.2.6 unless noted below.

- **Controls binding:** routine Bind no longer closes healthy USB device readers.
  Calibrate stays on the saved axis, retries a reader that initially failed, and
  shows paused/assigned-controls status more clearly. A MOZA handbrake was
  cleared, rebound and driven successfully; a fresh T300/TSS bind still needs
  testing. If a bind fails, create a support file while the failure is visible,
  before reinstalling.
- **Shift vibration (experimental):** off by default. In **F6 → Advanced → FFB**,
  enable it for a short wheel rumble when the player's gear engages. It starts
  at 5% nominal force with a 0–20% range. It does not change the gearbox or
  gamepad rumble; landing and crash cues take priority. Please report whether
  the timing and strength feel useful on your wheel.
- **Crash kick:** unchanged from 0.2.6. If you had a saved crash strength, it
  stays at that value; the 50% default only applies to new settings. The owner
  found their saved strength was still 19.5%, so a physical 50% comparison is
  still pending. Crash kick remains off by default for new users.

Download **ArtOfSimRally-0.2.7-rc.2.zip** from Assets. Close the game, extract
the ZIP into a fresh folder, and run **Install.bat**. Unity Mod Manager 0.27.0
or newer must already be installed for art of rally. The installer preserves
existing settings. See the [setup guide](https://github.com/d-b-c-e/art-of-sim-rally/blob/main/docs/SETUP.md).

This ZIP was built locally from clean source and passed all 16 automated gates,
including recorded-drive replay, Unity Mono checks and installer tests. The
exact ZIP is installed on the owner's PC, but this candidate has **not** yet
had a physical shift/crash feel test. This is a prerelease, not a claim that
the complete wheel, camera and motion-rig test matrix passed. Please include
your wheel/driver, car, stage and a support file when reporting a problem.
