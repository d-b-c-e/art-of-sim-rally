# art of sim rally 0.2.6

This release brings the new Wheel settings panel to everyone, adds explicit
calibration and device selection for separate USB controls, and includes an
optional experimental crash kick. The owner's recent testing of the installed
candidate was good overall and they requested this release. That acceptance does
not cover every wheel, camera combination or motion rig.

- Press **F6** for Wheel settings. Simple has Controls, FFB, Cameras, Telemetry and
  Help; Advanced adds tuning to those same pages. UMM scale is the default for
  new settings. Bindings have clearer groups and compact actions.
- Bind a wheel, pedals or a separate handbrake on the Controls page. Preview
  travel, calibrate and save explicitly. Each row can use a different USB device;
  existing game-controlled rows can stay unbound. Saved bindings and FFB choices
  use device identity rather than a shifting enumeration index.
- In FFB, follow the mod's saved Steering binding or explicitly choose the wheel
  that supplies force. A missing saved wheel remains visible and unavailable;
  Refresh retries after reconnecting it. F8/Stop FFB saves Off until you choose
  On again.
- Rebind camera adjustment shortcuts to a keyboard without a numpad or to USB
  buttons. **Open game bindings** now hands input back to the game's native
  Controls screen; the owner confirmed the previous dead-input symptom is fixed.
- Landing vibration remains on by default at strength 5; its optional range is
  now 0–40. The **experimental crash kick** is off by default at strength 50,
  range 0–100. It sends a brief constant-force pulse separate from steering.
  These wheel effects do not change SimHub telemetry or motion gain.
- Reduce avoidable driving I/O from native force tracing. Support files include
  finer 33/50/100 ms frame-interval counts and landing contact timing to help
  diagnose reports without running the separate developer recorder.
- Pin the official wheel toolkit v0.15.0; its five shipped native and managed
  files match the binaries tested in the previous candidate.

Download **ArtOfSimRally-0.2.6.zip** from this release's Assets, close the game,
extract it into a fresh folder, and run **Install.bat**. Unity Mod Manager 0.27.0
or newer must already be installed for art of rally. The installer preserves
settings and verifies the payload. See the [first-drive instructions](https://github.com/d-b-c-e/art-of-sim-rally#readme)
and [setup guide](https://github.com/d-b-c-e/art-of-sim-rally/blob/main/docs/SETUP.md).

The release is built and tested locally; GitHub hosts the verified ZIP and its
adjacent SHA-256 file without rebuilding it. Recorded drives, Unity Mono checks,
telemetry and input regressions, native exports, package integrity and installer
tests run in the 16-check gate. The final artifact has its own gate and receipt.

**Still open:** experimental crash feel and the full device/camera/focus matrix
vary by setup. The Haapajarvi landing-timing and stage-start hitch reports are
not diagnosed from the owner's different runs. SimHub motion amplification was
deferred. See [known issues](https://github.com/d-b-c-e/art-of-sim-rally/blob/main/docs/KNOWN-ISSUES.md); please include a support file
and your wheel/driver, car and stage when reporting a problem.
