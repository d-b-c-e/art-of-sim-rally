# art of sim rally 0.2.7

This release improves binding recovery for separate USB controls and adds an
optional wheel rumble when a gear engages. It promotes the behavior in the
0.2.7-rc.2 test build without changing steering, landing, crash or SimHub
telemetry tuning.

- **Controls:** Bind keeps healthy USB readers open and retries an initially
  failed reader. Calibrate stays on the saved axis; the Controls page shows
  paused/assigned-controls status more clearly. The owner's MOZA handbrake
  rebound successfully, but a fresh Thrustmaster T300/TSS bind still needs
  testing. If binding fails, create a support file while the failure is visible,
  before reinstalling.
- **Shift vibration:** off by default. Enable it at **F6 → Advanced → FFB** for
  a short wheel rumble when the player's gear engages. Initial strength is 5%
  of nominal force, adjustable from 0–20%. It does not alter shifting or
  gamepad rumble. Landing and crash effects take priority.
- **Crash kick:** unchanged. Existing saved strengths remain intact; the 50%
  default applies only to new settings. A physical 50% comparison is still
  pending. Crash kick remains off by default for new users.

Download **ArtOfSimRally-0.2.7.zip** from Assets. Close art of rally, extract
the ZIP into a fresh folder and run **Install.bat**. Unity Mod Manager 0.27.0
or newer must already be installed for the game. The installer preserves your
settings. See the [setup guide](https://github.com/d-b-c-e/art-of-sim-rally/blob/main/docs/SETUP.md).

The final-labelled ZIP was built locally and passed all 16 automated gates,
including recorded-drive replay, Unity Mono checks and installer tests. The
owner accepted promotion of the tested RC2 behavior, but the final ZIP has not
yet had a physical shift/crash feel test or a fresh T300/TSS bind. The broader
wheel, camera and motion-rig matrix remains open. Please include your
wheel/driver, car, stage and a support file with a problem report.
