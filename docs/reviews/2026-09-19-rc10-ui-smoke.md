## Follow-up

UMM clamps a zero size preference to960×720. RC10 instead treated zero as no
host constraint and set a1720px minimum content width; UMM scrolled that content
inside its unchanged window. Offline screen-bound checks missed this host bound.

The successor reads actual UMM window size without writing host preferences,
fixes outer and nested content widths, wraps pages to three columns at default4K,
and gives view selection its own row. Stop/Close share the title row. Page height
uses the actual/default host height. New fixtures cover zero preferences and
actual960px width; a local assembly check verifies the read-only host-size seam.
