# art of sim rally 0.2.3

This maintenance release fixes camera handback, reduces settings writes while
driving, improves recovery and diagnostics, and adopts the shared wheel toolkit
without changing the force-feedback tune.

- Restore the camera transform and field of view when returning from bonnet or
  bumper views, including replay and stage-end transitions.
- Defer learned-axis settings saves until driving stops; retry failed writes
  and preserve the previous settings file. Release outputs before saving on exit.
- Recover telemetry after correcting a failed destination or restarting it.
- Use toolkit **v0.12.0** (native **0.5.0**) for device access and the existing
  force curve. New wheel selections retain an exact device identity.
- Include accurate build/component versions and file hashes in support reports.
- Verify package integrity during installation and preserve existing settings.

Download **ArtOfSimRally-0.2.3.zip**, close the game, extract it and run
**Install.bat**. Unity Mod Manager must already be installed. Existing settings
and bindings are retained. The adjacent SHA-256 file identifies the archive.

## Validation and remaining reports

The owner's RC6 drive feedback was: "no stutter, camera worked great, and no
issues with the controls so far." A local game log also confirms toolkit loading
and live force evaluation. The final package uses the same production source and
toolkit as RC6, with updated release identity and documentation.

The final package is checked by the full automated suite: force regressions,
settings/lifecycle tests, telemetry loopback, native exports, version and package
integrity, installer upgrade/uninstall, and exclusion of developer recorder code.
Recording and replay tools are development-only and are not included in this ZIP.

The complete attended checklist remains pending, including a drive of the
final-labelled archive, explicit FFB focus recovery, saved controls after restart,
and live SimHub receipt. No real capture corpus was supplied to automated replay.
Publication follows the owner's release request and scoped RC6 smoke result;
it does not mark those outstanding checks passed.

Fanatec confirmation, RWD snapback/tuning and the original stage-stutter report
remain open. Issue #1's reporter separately resolved their camera symptom by
unplugging a PS5 controller; that is not a confirmed diagnosis of the camera
handback defect. No new damper/impact effects or physics changes are introduced.
