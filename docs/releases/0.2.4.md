# art of sim rally 0.2.4

This release fixes unnecessary game-manager initialization that could flood the
game with ghost-download requests, adds camera-key remapping, and improves direct
input, camera compatibility, telemetry and support reports.

- Read existing game state without accidentally constructing managers in menus.
  The owner's retest showed one normal initialization and no initialization,
  connection or exception flood.
- Remap all 11 camera adjustment keys in the mod panel. Camera edits retain
  pending saves across view changes and retry failed writes while idle.
- Fix pedal Flip, saved steering inversion, stale input after reader loss and
  failed assignment baselines. Live input values help set up a separate USB
  handbrake; the existing analog path preserves partial lever travel.
- Avoid conflicting with Nexus CameraMod: when it is loaded, its camera views
  keep control and our bonnet/bumper mounts are suspended. Saved settings remain.
- Correct telemetry suspension units and vehicle-local motion axes, reset
  acceleration history across transitions, and handle failed UDP sends.
- Add opt-in frame-hitch counts, loaded-mod/input details and bounded recent logs
  to support files. Clarify the legacy steering-limiter checkbox's behavior.

Download **ArtOfSimRally-0.2.4.zip**, close the game, extract it and run
**Install.bat**. Unity Mod Manager must already be installed. Settings and bindings
are preserved. The adjacent SHA-256 file identifies the archive.

**Telemetry users:** corrected units/axes can change shaker or motion response.
Check your dashboard channels and compare output at a conservative level before
returning to your normal setup. Telemetry does not add wheel force-feedback effects.

## Validation and remaining reports

The owner tested the installed RC5 on a MOZA R12 and reported, "I think everything
looks good," then requested this release. Its Unity log contains no initialization
errors, connection failures or exceptions; the previous RC4 run contained tens of
thousands. This confirms that the error flood was absent in the retest, without
claiming every intermittent slowdown on other systems has the same cause.

The final package uses the same production source, numeric version, force tune and
toolkit v0.12.0 (native 0.5.0) as RC5. Release identity and documentation differ.
It passes the full 16-check local automated suite, including the real game-field
contract, force/input regressions, camera/save lifecycle, telemetry UDP, native
exports, package integrity, installers and exclusion of developer recorder code.

The full attended scenario matrix and a drive of the final-labelled artifact
remain pending. TSS/Fanatec-specific confirmation, combined-camera-mod screen
checks and motion/shaker comparisons remain open. Publication follows the owner's
RC5 acceptance and release instruction; those outstanding checks are not marked
passed. No new wheel effects, force tune, physics or assist behavior changes.
